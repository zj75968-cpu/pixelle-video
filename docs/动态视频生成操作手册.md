# Pixelle-Video 动态短视频生成操作手册

这份文档面向第一次使用 Pixelle-Video 的同事或交付对象，目标是把学习成本降到最低：照着做，可以启动 Web UI、检查配置、生成动态 MP4、查看历史记录，并理解什么时候需要 ComfyUI、什么时候不需要。

> 当前本机已验证：Web UI 可访问，DeepSeek LLM 测试成功，本地 ComfyUI 可连接，ComfyUI 已识别 RTX 3060 GPU，已安装视频工作流需要的基础插件。当前没有下载 FLUX/AnimateDiff 等大模型，所以 ComfyUI 生图/生视频需要先补模型文件。

最终产物是 `.mp4` 文件，适合抖音、视频号、小红书、B 站竖屏视频等平台继续剪辑或发布。

当前已经生成了一批动态样片，路径在：


- 竖屏短视频：`720x1280`

- 不是纯文字模板：包含程序化动态背景、运动元素、进度条、字幕、中文配音
- 已写入 Pixelle-Video 的 History 索引

## 3. 启动 Web UI

推荐启动命令：

```powershell
cd "D:\vscocde file\github-video-项目\Pixelle-Video"
$env:NO_PROXY = "127.0.0.1,localhost"
$env:no_proxy = $env:NO_PROXY
uv run streamlit run web/app.py --server.port 8501
```

浏览器打开：

```text
http://localhost:8501
```

为什么要设置 `NO_PROXY`：

- 有些电脑开了本机代理，例如 `127.0.0.1:7890`。
- Pixelle-Video 访问本机 ComfyUI 时也走 `127.0.0.1`。
- 如果没有 `NO_PROXY`，请求可能被代理劫持，表现为 Web UI 测试 ComfyUI 返回 `502`。

### 5.2 本机 ComfyUI 启动命令

如果桌面脚本可用，优先双击：

```text
C:\Users\Administrator\Desktop\启动 ComfyUI（FLUX）.bat
```

如果要手动启动，可用：

```powershell
$py = "C:\ComfyUI\.venv\Scripts\python.exe"
$main = "D:\AI\ComfyUIDesktop\resources\ComfyUI\main.py"
$extra = "$env:APPDATA\ComfyUI\extra_models_config.yaml"

& $py $main `
  --listen 127.0.0.1 `
  --port 8188 `
  --base-directory C:\ComfyUI `
  --user-directory C:\ComfyUI\user `
  --extra-model-paths-config $extra `
  --disable-auto-launch `
  --enable-manager `
  --log-stdout
```

注意：不要加 `--cpu`，否则生图/生视频会走 CPU，非常慢。

## 6. 当前已安装的 ComfyUI 插件

已经安装到：

插件：


验证节点是否被 ComfyUI 识别：

```powershell
$env:NO_PROXY = "127.0.0.1,localhost"
$env:no_proxy = $env:NO_PROXY

@'
import json, urllib.request
with urllib.request.urlopen("http://127.0.0.1:8188/object_info", timeout=30) as r:
    data = json.load(r)
for key in ["VHS_VideoCombine", "easy int", "UNETLoader", "DualCLIPLoader"]:
    print(key, key in data)
'@ | uv run python -
```

全部输出 `True`，说明插件加载成功。

## 7. 为什么当前不直接跑 ComfyUI 生视频

Pixelle-Video 自带的本地 ComfyUI 工作流包括：

```text
workflows/selfhost/image_flux.json
workflows/selfhost/image_qwen.json
workflows/selfhost/video_animatediff_sd15.json
```

这些工作流依赖大模型文件。当前插件已装好，GPU 也能识别，但模型文件还没下载。

缺模型时，常见报错会类似：

```text
model not found
clip not found
vae not found
```

所以当前先用“本地动态样片生成器”交付动态 MP4；等模型文件补齐后，再切到 ComfyUI 生图/生视频模式。

## 9. 生成 10 条动态 MP4 的最快方法

当前项目新增了一个批量动态样片脚本：

```text
scripts/generate_dynamic_samples.py
```

运行：

```powershell
cd "D:\vscocde file\github-video-项目\Pixelle-Video"
$env:NO_PROXY = "127.0.0.1,localhost"
$env:no_proxy = $env:NO_PROXY
uv run python scripts\generate_dynamic_samples.py --count 10
```

脚本会自动完成：

1. 准备 10 个短视频主题。
2. 用 Edge TTS 生成中文配音。
3. 用程序化动态视觉生成运动画面。
4. 用 FFmpeg 合成 MP4。
5. 为每条视频写入 `metadata.json` 和 `storyboard.json`。
6. 重建 Pixelle 的 History 索引。
7. 输出 manifest 文件。

生成结果：

```text
output/dynamic_日期_时间_序号_标题/final.mp4
```

例如：

```text
output/dynamic_20260507_012313_01_三个提升专注力的小方法/final.mp4
```

### 9.1 生成复杂场景动画

如果交付要求是“复杂动画”，不要用 `generate_dynamic_samples.py`，改用复杂场景动画脚本：

```powershell
cd "D:\vscocde file\github-video-项目\Pixelle-Video"
$env:NO_PROXY = "127.0.0.1,localhost"
$env:no_proxy = $env:NO_PROXY
uv run python scripts\generate_complex_animation_samples.py --count 10
```

这个脚本会生成更接近动画短片的 MP4，而不是简单图形动效。每条视频包含：

- 角色动作
- 具体场景，例如桌面、卧室、晨间房间、画廊、AI 工具台、复盘白板
- 道具动画，例如手机提醒、番茄钟、清单、窗帘、画框、任务卡片、日历
- 镜头感和分层视差
- 分段字幕和中文配音
- Pixelle History 记录

当前本机已生成的复杂动画批次：

```text
output/complex_20260507_091150_*/final.mp4
output/complex_20260507_091150_preview_grid.jpg
output/complex_20260507_091150_manifest.json
```

如果只想快速检查效果，先打开预览拼图：


### 9.2 生成 20 秒 ComfyUI 合成版复杂动画

如果明确要求“用 ComfyUI 生成/合成，并且时长拉到 20 秒”，使用：

```powershell
cd "D:\vscocde file\github-video-项目\Pixelle-Video"
$env:NO_PROXY = "127.0.0.1,localhost"
$env:no_proxy = $env:NO_PROXY
uv run python scripts\generate_comfy_complex_20s.py --duration 20
```

这条流程会执行：

1. 生成中文配音。
2. 生成 20 秒、15fps、720x1280 的 PNG 帧序列。
3. 调用 ComfyUI API。
4. 在 ComfyUI 中执行 `VHS_LoadImagesPath -> VHS_LoadAudio -> VHS_VideoCombine`。
5. 从 ComfyUI 输出目录复制最终 MP4 到 Pixelle `output/`。
6. 写入 `metadata.json`、`storyboard.json`、manifest、预览图和 History。

当前本机已生成：

```text

output/comfy_complex_20260507_110924_manifest.json
output/comfy_complex_20260507_110924_preview_grid.jpg
output/comfy_complex_20260507_110924_contact_sheet.jpg
```

验收结果：

```text

video: 720x1280, 15fps
audio: AAC
ComfyUI output: C:\ComfyUI\output\pixelle_comfy_20s\comfy_complex_20260507_110924_01_journey_20s_00001-audio.mp4
```

注意：当前本机没有 AnimateDiff/FLUX 等大模型权重，所以这条 20 秒流程使用 ComfyUI 做帧序列与音频合成，不是由 ComfyUI 大模型直接生成画面。要切换成真正 ComfyUI AI 生视频，需要先补齐第 8 节的模型文件。

## 13. API Key 获取方式

### 13.1 DeepSeek

用途：

- 生成文案
- 生成分镜
- 生成提示词

获取：

```text
https://api-docs.deepseek.com/api/deepseek-api/
```

配置：

```text
Base URL：https://api.deepseek.com
Model：deepseek-chat
API Key：自己的 DeepSeek Key
```

### 13.2 Comfy Cloud

用途：

- 用 Comfy 官方云端跑工作流
- 适合不想维护本地 GPU 的团队

文档：

```text
https://docs.comfy.org/development/cloud/overview
```

要点：

- Base URL 是 `https://cloud.comfy.org`
- API Key 放在 `X-API-Key` 请求头
- 创建 API Key 后只显示一次，要马上保存
- 不要把 Key 写进 Git 或截图

### 13.3 RunningHub

用途：

- 用 RunningHub 云端跑 ComfyUI 工作流
- 适合批量任务、无本地显卡、或本地模型不完整的情况

文档：

```text
https://www.runninghub.ai/runninghub-api-doc-en/doc-8287463
```

获取方式：

1. 登录 RunningHub。
2. 打开右上角头像/资料浮层。
3. 查看 API Key。
4. 确认账号有可用会员或余额。
5. 先在网页端手动跑通对应 workflow，再把 workflow ID 用到 API。

## 16. 常见问题

### 16.1 Web UI 连接 ComfyUI 失败

先确认：

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8188/system_stats
```

如果命令行正常、Web UI 失败，设置：

```powershell
$env:NO_PROXY = "127.0.0.1,localhost"
$env:no_proxy = $env:NO_PROXY
```

然后重启 Streamlit。

### 16.2 ComfyUI 只显示 CPU

检查启动命令里是不是带了：

```text
--cpu
```

如果有，去掉后重启 ComfyUI。

### 16.3 视频工作流缺节点

检查：

```text
VHS_VideoCombine
easy int
```

如果没有，安装：

```powershell
cd C:\ComfyUI\custom_nodes
git clone https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite.git
git clone https://github.com/yolain/ComfyUI-Easy-Use.git

C:\ComfyUI\.venv\Scripts\python.exe -m pip install -r C:\ComfyUI\custom_nodes\ComfyUI-VideoHelperSuite\requirements.txt
C:\ComfyUI\.venv\Scripts\python.exe -m pip install -r C:\ComfyUI\custom_nodes\ComfyUI-Easy-Use\requirements.txt
```

然后重启 ComfyUI。

### 16.4 视频工作流缺模型

表现：

```text
model not found
vae not found
clip not found
```

处理：

1. 看报错里缺哪个文件。
2. 下载对应模型。
3. 放入 `D:\ComfyUI-Data\models` 下的对应目录。
4. 重启 ComfyUI。
5. 再点 Pixelle 的「生成视频」。

### 16.5 `HTML rendering failed:`

Windows 下 Playwright Chromium 渲染 HTML 需要支持 subprocess 的事件循环。当前项目已在：

```text
web/utils/async_helpers.py
```

里处理为 Proactor event loop。修改后必须重启 Streamlit。

### 16.6 Edge TTS 偶发没有音频

表现：

```text
No audio was received
```

处理：

- 重试一次。
- 换一个音色。
- 检查网络。
- 批量脚本已内置自动换音色重试。

## 17. 推荐团队使用方式

如果目标是低学习成本、稳定批量出片：

1. 先使用 `scripts/generate_dynamic_samples.py` 批量生成样片。
2. 选出风格最适合账号定位的 2-3 条。
3. 再根据账号领域修改脚本里的 `SAMPLES`。
4. 每次批量生成 10 条。
5. 在 History 里审核。
6. 只导出通过审核的 MP4。

如果目标是更高画质：

1. 先补齐 ComfyUI 模型。
2. 用 Pixelle Web UI 的「生成插图」跑 1 条。
3. 再用「生成视频」跑 1 条。
4. 对比耗时、画质、稳定性。
5. 决定是否用本地 GPU，还是切 RunningHub / Comfy Cloud。
