# PRD — 图文帖子流水线 + 小红书手机自动发布

**版本**: 1.0  
**日期**: 2026-05-03  
**状态**: 待执行

---

## 1. 背景与目标

Pixelle-Video 目前专注于 **AI 自动生成短视频**。本次迭代新增两个独立但协作的能力模块：

| 模块 | 描述 |
|------|------|
| **图文帖子流水线** | 生成小红书风格的多图轮播帖子（3-9 张 AI 图 + 标题 + 正文） |
| **手机自动发布系统** | 通过 ADB 连接 2-5 台实体 Android 手机，全自动将帖子发布到小红书 App |

---

## 2. 用户故事

### 2.1 图文帖子流水线

- 作为创作者，我输入一个主题，系统自动生成一组适合小红书的多图帖子，不需要我手动设计任何内容。
- 作为创作者，我希望每张图片都有独立的视觉提示词，风格统一但内容各异，形成连贯的叙事。
- 作为创作者，我希望输出的正文包含合适的话题标签（#话题）。

### 2.2 手机自动发布系统

- 作为运营者，我有 2-5 台 Android 手机，每台登录不同的小红书账号，我希望能在 Web 界面统一管理它们。
- 作为运营者，我希望系统能把生成好的帖子（图片+文案）推送给指定手机并自动发布。
- 作为运营者，我希望可以为每台手机配置不同的发帖主题/风格，系统自动按主题生成内容。
- 作为运营者，我希望能设置发布时间队列，让不同手机在不同时间段批量发布，避免账号风控。

## 3. MVP 功能边界

### ✅ 本次 MVP 范围内

**图文帖子流水线：**
- 新增 `ImageTextPostPipeline` 流水线
- 输入：主题文字 + 可选的图片风格/模板
- 输出：单个任务文件夹，包含：
  - `images/1.png` … `images/N.png`（3-9 张，数量可配置）
  - `post.json`（标题、正文、话题标签列表）
  - `post_preview.html`（本地预览页，轮播展示）
- Web UI 新增「图文帖子」标签页，和视频生成页面同级

**手机自动发布系统：**
- 通过 ADB（USB 或 WiFi ADB）连接 Android 手机
- Web UI 新增「发布管理」页面，展示设备列表、在线状态
- 每台设备可配置：备注名、默认发帖主题、发帖间隔（分钟）
- 支持一键将已生成的图文帖子推送到指定设备并发布
- 内置发布队列：可设置未来发布时间，队列按序执行
- 发布日志：每次操作结果（成功/失败/截图）记录并在 UI 展示

### ❌ 本次 MVP 不包含

- iOS 设备支持（需要 tidevice + Appium，复杂度高）
- 视频帖子的自动发布（仅图文）
- 小红书私信、评论互动自动化
- 账号注册/登录自动化（用户手动登录小红书，系统只做发帖操作）
- 多平台发布（抖音、微博等）
- 帖子数据回收（点赞、评论数统计）
- 云端设备农场（仅本地 ADB）

## 4. 功能详细描述

### 4.1 图文帖子流水线

#### 输入参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `topic` | string | 帖子主题，例如「减肥餐食谱」 |
| `image_count` | int | 图片数量，3-9，默认 6 |
| `style` | string | 图片风格，可选：写实/插画/扁平等 |
| `template_size` | string | 图片尺寸，默认 1080x1080 |
| `post_tone` | string | 文案语气：干货/种草/故事/清单 |
| `hashtag_count` | int | 话题标签数，默认 5 |

#### 输出结构

```
output/{task_id}/
  images/
    1.png
    2.png
    ...N.png
  post.json          # { title, body, hashtags, created_at }
  post_preview.html  # 本地轮播预览
```

#### 处理流程

1. LLM 生成帖子文案（标题 + 每张图的描述 + 正文 + 话题标签）
2. 对每张图片，生成独立的图片提示词（使用现有 ComfyUI/图片生成服务）
3. 并行生成全部图片
4. 拼装 `post.json` 和 `post_preview.html`

### 4.2 手机自动发布系统

#### 设备管理

- 扫描 ADB 已连接设备（`adb devices`）
- 设备信息：序列号、型号、Android 版本、在线状态
- 设备配置：备注名、默认主题、最小发帖间隔
- WiFi ADB：支持填写 `IP:端口` 手动连接

#### 发布流程（每次发帖）

1. 将 `images/` 中图片推送到手机相册（`adb push` + `adb shell` 媒体扫描）
2. 启动小红书 App（`uiautomator2 app_start`）
3. 点击「+」创建笔记
4. 选择「图文」类型
5. 从相册选择推送的图片（按顺序）
6. 粘贴标题（`post.json.title`）
7. 粘贴正文（`post.json.body`）
8. 点击「发布」
9. 等待发布确认，截图留存
10. 删除手机临时图片

#### 发布队列

- 字段：任务 ID、设备序列号、帖子路径、计划时间、状态、重试次数
- 状态流转：`pending` → `running` → `done` / `failed`
- 失败自动重试 3 次（间隔 60 秒）
- 队列由后台调度器轮询执行（APScheduler）

#### 风控建议（配置项，非强制）

- 发帖间隔：同一设备最短 N 分钟（可配置，默认 30 分钟）
- 每日上限：同一设备每天最多发 M 篇（可配置，默认 5 篇）

## 5. 验收标准

### 图文帖子流水线

- [ ] 输入主题，点击生成，得到 ≥3 张图片 + post.json
- [ ] post.json 包含 title、body、hashtags 三个字段
- [ ] post_preview.html 能在浏览器正确展示轮播
- [ ] 历史记录页面能看到图文帖子任务
- [ ] 失败时有清晰的错误提示

### 手机自动发布系统

- [ ] 连接 USB 的 Android 手机能在设备列表中出现
- [ ] WiFi ADB 设备可手动添加
- [ ] 点击「立即发布」能将帖子图片推送到手机并完成发布
- [ ] 队列中的任务在计划时间自动执行
- [ ] 每次发布结束后有状态记录和截图
- [ ] 多台设备之间的队列互相独立、互不干扰
