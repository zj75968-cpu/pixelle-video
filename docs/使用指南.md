## 2. 推荐方式：Windows 一键整合包

如果你只想快速体验，建议直接下载官方 Windows 一键整合包：

- 地址：https://github.com/AIDC-AI/Pixelle-Video/releases/latest
- 下载后解压
- 双击 `start.bat` 启动
- 浏览器自动打开：`http://localhost:8501`

> 这种方式无需手动安装 Python、uv、ffmpeg，最适合 Windows 用户。

## 3. 源码运行方式（已克隆到本地）

### 3.1 环境准备

你需要安装以下工具：

- `uv`：用于运行项目并自动安装依赖
- `ffmpeg`：用于视频编解码处理

#### 安装 uv

请参考 uv 官方文档安装：
https://docs.astral.sh/uv/getting-started/installation/

安装成功后运行：

```powershell
uv --version
```

#### 安装 ffmpeg

Windows 用户：

- 下载地址：https://ffmpeg.org/download.html
- 解压后，将 `bin` 文件夹路径加入系统环境变量 `PATH`
- 验证：

```powershell
ffmpeg -version
```

### 3.2 启动项目

在仓库根目录下运行：

```powershell
cd "d:\vscocde file\github-video-项目\Pixelle-Video"
uv run streamlit run web/app.py
```

成功后，浏览器会自动打开：

```text
http://localhost:8501

### 3.3 Web 界面配置
最后检查是否有代理干扰本地接口，确保 `NO_PROXY=127.0.0.1,localhost` 已生效。

进入 Web 页面后，首次使用需要配置：

- **LLM 配置**：填写语言模型地址、模型名称与 API Key
- **图像生成配置**：配置 ComfyUI 本地地址或 RunningHub API Key
- **TTS 配置**：选择支持的语音合成工作流

## 4. 使用流程

1. 打开 Web 界面
2. 在“内容输入”栏输入主题或完整文案
3. 选择视频模板、图像风格、语音设置等
4. 点击“生成视频”
5. 生成完成后在页面预览，并可在 `output/` 文件夹中找到生成结果

## 5. 重要目录说明

- `web/`：Web 前端入口
- `workflows/`：ComfyUI / TTS / 图像处理工作流配置
- `bgm/`：背景音乐文件目录
- `templates/`：视频模板文件
- `output/`：默认输出目录（生成的视频文件）

## 6. 额外提示

- 如果你想避免复杂配置，优先使用 Windows 一键整合包
- 如果你有本地显卡，建议本地部署 ComfyUI + 本地 LLM，可降低使用成本
- 生成视频前，先确保所有服务（LLM、ComfyUI、TTS）都已正确配置并能连通
当前项目已经做了一个关键优化：

- 当使用视频工作流（例如 `selfhost/video_animatediff_sd15.json`）时，
- 如果你选择的是 `image_*` 或 `static_*` 模板，系统会默认走“视频保真直出”（不再强制叠加整屏图文模板），
- 只做音频合并，减少“卡片感”和“二次压画质”的问题。

如果你确实需要模板字幕叠加，请改用 `video_*` 模板（例如 `video_default.html`）。

### 7.1 推荐参数（先追求真人感）

- `media_workflow`: `selfhost/video_animatediff_sd15.json`
- `frame_template`: `1080x1920/image_default.html`（会触发视频保真直出）
- `n_scenes`: `1`（先验证质量）
- `video_fps`: `15`

### 7.2 API 快速验证命令

```powershell
cd "d:\vscocde file\github-video-项目\Pixelle-Video"
$env:NO_PROXY = "127.0.0.1,localhost"
$env:no_proxy = $env:NO_PROXY

$body = @{
	mode = "generate"
	n_scenes = 1
	frame_template = "1080x1920/image_default.html"
	media_workflow = "selfhost/video_animatediff_sd15.json"
	video_fps = 15
} | ConvertTo-Json -Depth 6

Invoke-RestMethod -Method Post `
	-Uri "http://127.0.0.1:8001/api/video/generate/sync" `
	-ContentType "application/json" `
	-Body $body
```

### 7.3 说明

- AnimateDiff SD1.5 可以做“动态真人感”，但不是“真实拍摄同款人脸复刻”。
- 如果你更在意稳定性和本地维护成本，建议优先使用 AnimateDiff 或素材驱动流程（i2v / 数字人）。
